# Dev template and container icons

`data/dev-templates/<id>.png` (ids from `../dev-templates.json`) and
`data/containers/<id>.png` (from `../containers.json`), 128×128, built into
the installer; one without an icon gets a letter tile. From
[devicon](https://github.com/devicons/devicon) (MIT), except typst, vlang,
odin, meilisearch and minio from [Simple Icons](https://simpleicons.org)
(CC0, in their brand colour) and valkey from
[dashboard-icons](https://github.com/homarr-labs/dashboard-icons)
(Apache-2.0). The logos are their owners' trademarks. No icon anywhere yet:
cue, dhall, hdl, lean4, nickel, opa, presenterm, protobuf.
