# Dev template and container icons

`data/dev-templates/<id>.png` (ids from `../dev-templates.json`) and
`data/containers/<id>.png` (from `../containers.json`), 128×128, built into
the installer; one without an icon gets a letter tile (a catalog test
requires one for every container). From
[devicon](https://github.com/devicons/devicon) (MIT), except typst, vlang,
odin, meilisearch, minio and nats from [Simple Icons](https://simpleicons.org)
(CC0, in their brand colour); valkey, clickhouse, couchdb, cassandra,
neo4j, surrealdb, opensearch, typesense, ollama, qdrant, chroma, mailpit,
keycloak, adminer, pgadmin, gitea, sonarqube, grafana, prometheus, jaeger,
azurite (Azure's logo), gcloud-pubsub (Google Cloud's) and
gcloud-firestore (Firebase's) from
[dashboard-icons](https://github.com/homarr-labs/dashboard-icons)
(Apache-2.0); memcached, weaviate and kafka from
[selfh.st icons](https://github.com/selfhst/icons) (CC BY 4.0); redpanda,
moto and postgis are their projects' GitHub organisation avatars; pgvector
is PostgreSQL's elephant (postgres.png). The logos are their owners'
trademarks. No icon anywhere yet: cue, dhall, hdl, lean4, nickel, opa,
presenterm, protobuf.
